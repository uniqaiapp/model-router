# AGENTS.md

This repository is an agent skill: **model-router** picks the cheapest LLM tier (fast / smart / premium) that can do a task, recommends a model per provider and estimates the cost before you run it. The full instructions are in `SKILL.md`; read it first.

## Working in this repo

- Zero dependencies: Node 18+ built-ins only. Do not add packages, a `package.json` with dependencies, or a lockfile.
- Run tests: `node tests/run.mjs`. Validate the price table: `node scripts/check.mjs`.
- Prices live only in `data/prices.json`. Every row has a `source` URL and a `checked` date. Never type a price into Markdown by hand; `references/price-table.md` is generated by `node scripts/table.mjs --write`.
- `examples/expected/*` are produced by the scripts and compared byte-for-byte in tests. Regenerate with `node scripts/regen-examples.mjs` after changing rules or prices.
- Keep `SKILL.md` under 500 lines; long material goes to `references/`.
- Author and maintainer is UniqAI <support@uniqai.app>; do not add personal names anywhere.

## Using this skill from another project

Copy or clone this repo, then follow "Install" in README.md. When the user asks which model to use, how much a prompt or batch will cost, or wants to cut LLM spend, follow `SKILL.md`: classify the task, pick the tier, run `scripts/cost.mjs` for the estimate, and show the reasons.
